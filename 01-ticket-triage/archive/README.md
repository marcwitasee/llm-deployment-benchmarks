Early scripts from the first step of the project, kept for reference: one timed call each to Claude (`step2_claude_call.py`) and GPT-OSS on Fireworks (`step2_fireworks_call.py`), a key check (`check.py`), and their logs (`results.csv`, `eval_results.csv`). The final pipeline is `step3_eval.py` in the folder above. To run these, copy them up one folder so they can import `bench_log.py`.
